# GW2 Tools Website & GW2 简体中文 Mod 网站

This is a project started at Aug 18, 2024, as the imagination of a tools website for GW2, and the website for [GW2 Simplified Chinese Mod](https://gw2.shoushou1106.org/zhcn) (renamed to Project GW Simplified Chinese). The tools website is repurposed to [LawnLink](https://github.com/shoushou1106/lawnlink), and Project GW Simplified Chinese website is still pending. I learned a lot of web development from this.
